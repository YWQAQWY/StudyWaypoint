StudyWaypoint 当前前端 UI 说明
============================
整理日期：2026-10-15
依据：当前仓库的 static/index.html、static/app.js、static/ai.js、static/style.css 和 desktop.py。
说明：这是代码对应的界面结构说明，不是运行截图；页面中的课程名称、天数和进度随用户导入的计划变化。

一、整体外观与窗口
------------------
桌面版使用 GTK 3 独立窗口，窗口内部由 WebKitGTK 显示本地网页界面；也可以只启动本机浏览器版。
默认窗口大小为 1180 × 780，最小窗口大小为 560 × 480。
桌面标题栏显示 StudyWaypoint，左侧有刷新按钮，右侧有导入计划、恢复备份、导出备份按钮。
网页顶部是一条深蓝色导航栏：左侧是绿色 W 标识、StudyWaypoint 名称和“导入计划 · 本地保存”；右侧依次是“今天”“课程日历”“AI 规划”“设置与备份”。
主内容区最大宽度约 1280 像素，浅灰绿色背景、白色圆角卡片、深蓝文字、青绿色主按钮和状态标签。
操作成功或失败时，右上角会短暂出现提示。页面底部有“个人学习计划 · 课程链接需联网打开 · 学习实验由你亲自完成”。

二、主要页面示意
----------------
以下为结构示意，实际卡片内容由当前计划和学习记录决定。

1. 今天

  [StudyWaypoint]   今天 | 课程日历 | AI 规划 | 设置与备份
  --------------------------------------------------------
  今日学习 / 今天学什么                 [打开今日任务] [查看全部天数]
  第几周 · 第几天 · 今日主题

  [当前计划：总天数/周数/小时] [已开始天数与进度条] [验收通过天数]
  [每周路线：Week 1 ... Week N，点击可跳至该周]

首次使用且尚未设置学习起始日时，首页改为显示“设定学习起点”，包含开始日期、时区输入框和“保存并开始”按钮。
如果当前日期不在计划范围内，首页提示此情况，并提供进入完整日历的按钮。

2. 课程日历

  [左侧：按周排列的课程主题导航]
  [右侧：当前周主题、计划小时数、七个 DAY 日期卡片、本周 LeetCode 链接]

点击某个 DAY 卡片进入当日任务详情。日历按周显示；每张日期卡片显示天数、日期（已设置起始日时）、任务标题、计划时长和当前状态。

3. 每日任务详情

  顶部：Week / Day、日期、任务名称、课程章节、返回日历按钮
  指标卡：今日计划时长 | 实际学习时长 | 完成率和验收通过率

  主栏：                              侧栏：
  [01 课程阅读：链接、时长、打卡]      [学习计时：开始/继续、暂停/结束、补录]
  [02 动手练习：步骤、产物、验证、打卡] [任务状态与学习笔记]
  [03 交付物与验收：逐项状态与证据]    [添加证据：类型、内容、关联验收]
  [本日 LeetCode（存在时）]           [调整理论/实践/验收分钟预算]
  [04 今日复盘：成果、测试、卡点、明日事项]

阅读和练习打卡与验收状态分开显示。验收项可选状态、关联已保存的证据并填写审核备注。证据目前通过表单保存文字、URL、文件路径、Git commit、测试日志等内容；文件路径作为文字记录。

4. AI 规划

  顶部：AI 规划 / 从目标讨论到可导入课程
  [收起/显示计划侧栏]

  主栏：                              右侧栏：
  [讨论学习目标：对话记录]             [实时计划预览]
  [输入消息、发送、联网检索、取消]     [API 配置和搜索设置]
  [本轮检索来源（可展开）]
  [旧版手动生成草稿（可选，可展开）]

“实时计划预览”显示草稿状态、修订号、计划名称、学习目标、周期、每周/每日时长、资源偏好、可展开的学习阶段和任务、已发现资源、待确认事项及建议。最近修改的阶段或任务会高亮。关键内容齐备后，可点“确认计划并导入”；成功后显示“查看导入的计划”。
AI 配置区包含 OpenAI 兼容 API 的基础地址、模型 API Key、模型名称和推理强度；搜索区包含 SearXNG 地址、第三方搜索开关、Brave Search API Key、保存及连接测试按钮。第三方搜索关闭时，Brave 配置区域隐藏。
聊天区包含用户/AI 消息、学习目标输入框、“发送给模型”“联网检索系统课程”“取消当前请求”，以及检索状态和来源。普通聊天不要求已配置搜索。

5. 设置与备份

  [日期与时区：学习起始日、时区、保存]
  [计划库：当前计划/其他计划、切换、导入 v3 JSON、预览、确认导入、下载示例]
  [备份与恢复：下载当前计划备份、选择备份 JSON、确认恢复]

计划库会展示各计划的名称、ID、周数、天数、计划总小时数和格式版本；当前计划有醒目标记。导入时先校验并预览，随后由用户确认。

三、窄屏表现
--------------
屏幕宽度小于约 950 像素时，日历周导航和详情页侧栏会改为更紧凑的布局；AI 规划侧栏改为右侧抽屉式面板，并有遮罩层。
宽度小于约 620 像素时，顶栏导航可横向滚动，指标卡和大部分内容改为单列，日期卡片每行两张。

四、当前交互特点
----------------
所有页面使用同一套本地网页前端，在顶部导航中切换。界面语言主要为中文。
AI 草稿侧栏从应用保存的草稿状态读取，通过轮询同步；它不是直接把 AI 回复文本当作计划展示。AI 对话目前按请求完成后更新消息，搜索和生成过程中显示状态并支持取消。
桌面窗口内点击课程网站链接时，会交给系统默认浏览器打开。
