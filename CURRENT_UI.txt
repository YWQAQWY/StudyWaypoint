StudyWaypoint 当前桌面 UI 说明
============================
更新日期：2026-10-15
依据：static/index.html、static/app.js、static/ai.js、static/style.css、desktop.py。
本文件描述实际代码界面；课程名称、天数、草稿和进度以用户数据为准。

一、桌面窗口和整体样式
--------------------
桌面版是 GTK 3 独立窗口，内部使用 WebKitGTK 显示本机页面。默认大小 1180 × 780，最小 560 × 480。原生标题栏保留刷新、导入计划、恢复备份和导出备份按钮。
窗口内容是左侧导航 + 右侧学习工作区。左侧导航依次为“今天”“课程日历”“AI 规划”“设置与备份”，支持图标/文字模式与仅图标模式；当前页面有滑动的选中背景。顶部工具栏显示页面名称和明暗主题快捷按钮。
界面采用系统字体、圆角卡片、克制的阴影和青绿色品牌色。浅色、深色及跟随系统三种主题可在“设置与备份 → 外观”选择。导航状态、主题、AI 计划栏宽度和阶段折叠状态保存在本机数据目录的 ui_preferences.json，桌面服务换端口后仍可恢复。

二、主要页面
------------
1. 今天
   顶部说明当前学习日，提供“打开今日任务”和“查看全部天数”。下方显示当前计划总天数/周数/小时、已开始天数、验收通过天数和每周路线。首次使用时先填写开始日期和时区。

2. 课程日历
   左侧选择周次；右侧显示周主题、周计划小时数、七个 DAY 卡片及本周 LeetCode 链接。每个 DAY 卡片有日期、主题、计划时长和状态，点击进入每日详情。

3. 每日任务
   顶部三个指标为计划时长、实际学习时长、完成率/验收通过率。主栏依次为课程阅读、动手练习、交付物与逐项验收、可选 LeetCode 和今日复盘。右侧为学习计时、补录时长、任务状态与笔记、证据录入和每日预算调整。阅读/练习打卡与验收结果分别保存。

4. AI 规划
   双栏工作区：左栏是原有 AI 对话、检索状态、消息输入及可展开的旧版手动生成入口；右栏是应用持久化的结构化 PlanDraft 实时预览。两栏之间可拖动调整宽度，也支持键盘方向键。左栏消息区独立滚动，输入区位于底部；右栏任务区独立滚动，确认操作区固定在底部。
   草稿预览显示名称、目标、周期、学习时间、资源偏好、可展开的阶段/任务、已发现资源及待确认事项。阶段和任务使用稳定 ID 更新，近期变化柔和高亮；阶段折叠和阅读位置尽量保留。用户明确点击“确认计划并导入”后，依次显示生成、校验、导入及成功/失败状态。成功可直接进入导入的计划。
   OpenAI 兼容模型配置和 SearXNG/Brave 搜索配置位于“设置与备份”；尚未配置模型时，AI 页面也直接展示 API 配置表单。普通对话可不联网。兼容模型支持时，回复文本增量显示；不支持流式时回退普通回复。

5. 设置与备份
   计划库可切换计划、导入并预览 v3 JSON、下载示例计划。API 配置包含模型地址、密钥、模型名称、推理强度、SearXNG 地址、Brave 开关和连接测试。外观可选跟随系统/浅色/深色。还可修改学习起始日期、时区，以及下载或恢复当前计划备份。

三、桌面尺寸与动效
------------------
常规桌面宽度显示 AI 双栏；窗口变窄时优先保证聊天区，计划栏采用右侧覆盖面板，可随时收起。此处是窄桌面窗口布局，并非移动端 UI。
导航、计划栏和页面切换使用统一 Motion Tokens；系统启用“减少动态效果”后，会缩短或关闭位移动画。动画不会替代文字状态和焦点提示。
